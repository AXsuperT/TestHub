## 项目名称
TestHub — 企业级智能测试平台

## 项目角色
开发测试（全栈 + 测试自动化）

## 项目时间
2025-09 至 2025-12

## 项目简介
TestHub 是一套面向企业的一站式智能测试平台，覆盖测试用例管理、接口自动化测试、UI 自动化测试、性能测试、缺陷管理及 AI 智能助手等核心模块，帮助测试团队实现测试全流程的数字化、自动化与智能化。项目采用前后端分离架构，后端 Spring Boot 3 + MyBatis-Plus，前端 Vue 3 + Element Plus，测试执行引擎使用 Python（requests/Selenium/Locust），并集成大模型 API 实现测试用例自动生成与缺陷智能分析。

**GitHub**: https://github.com/AXsuperT/TestHub

## 技术栈
**后端**: Spring Boot 3 · MyBatis-Plus · MySQL · Redis · RabbitMQ · JWT · Knife4j · Apache HttpClient5
**前端**: Vue 3 · TypeScript · Element Plus · ECharts · Pinia · Vite
**测试引擎**: Python · requests · Selenium 4 · Locust · pytest
**AI**: 大模型 API 集成（测试用例生成 / 缺陷分析 / 报告总结）

## 主要职责

### 1. 接口自动化测试引擎开发
- 基于 Apache HttpClient5 自研 HTTP 接口测试执行引擎，支持 GET/POST/PUT/DELETE 请求、请求头/Query/Body 参数化、`{{varName}}` 变量替换与上下文传递
- 实现断言引擎，支持状态码、JSONPath、包含、正则匹配、数值比较（大于/小于/等于）、非空校验等 10+ 种断言操作符
- 支持测试套件批量执行与异步执行（@Async），执行记录与结果明细持久化到 MySQL，支持历史回放
- 使用 Postman + Knife4j 对 15+ 模块接口进行联调验证，覆盖正常流、异常流、边界值场景

### 2. 测试用例与缺陷管理模块
- 设计测试用例表结构（用例编号自动生成 TC-00001），支持功能/接口/UI/性能/安全等用例类型与 P0-P3 优先级
- 实现用例状态流转（草稿→待评审→已评审→废弃）与模块树管理
- 实现缺陷全生命周期管理（待处理→已分配→已修复→已验证→已关闭），支持严重程度分级与缺陷类型分类
- 使用 JUnit 5 + Mockito 对 Service 层核心逻辑编写单元测试，核心模块覆盖率 80%+

### 3. Python 测试执行引擎
- 基于 requests 封装接口自动化框架，支持用例 JSON 配置化、变量提取、断言验证、套件批量执行
- 基于 Selenium 4 封装 UI 自动化框架，步骤化执行 open/click/input/assert/screenshot，支持多浏览器
- 基于 Locust 实现性能压测引擎，统计 P50/P90/P95/P99 响应时间、RPS、错误率等指标

### 4. AI 智能助手模块
- 对接大模型 API，实现测试用例自动生成（覆盖正常/异常/边界/兼容性场景）
- 实现缺陷根因分析：输入缺陷描述与错误信息，输出根因、影响范围、修复建议、回归测试建议
- 实现测试报告智能总结：根据执行数据生成质量评估与上线建议

### 5. 数据可视化与前端
- 使用 ECharts 实现工作台数据看板：缺陷严重程度饼图、用例类型柱状图、执行趋势折线图
- 开发接口执行结果可视化页面，展示请求/响应/断言详情
- 使用 Element Plus 构建项目管理、用例管理、缺陷管理等 CRUD 页面

- AI 用例生成覆盖正常/异常/边界等场景，单需求可生成 10+ 条用例

## 面试要点提示

1. **断言引擎**: 能讲清楚如何设计断言规则、如何用 JSONPath 提取响应数据、如何处理变量传递
2. **HTTP 执行**: 能讲清楚 HttpClient5 的请求构建、响应解析、异常处理
3. **数据库设计**: 能讲清楚用例、缺陷、接口测试记录的表结构与关联关系
4. **异步执行**: 能讲清楚为什么用 @Async + RabbitMQ，如何保证执行记录的一致性
5. **AI 集成**: 能讲清楚如何设计 Prompt 让大模型生成结构化的测试用例
6. **单元测试**: 能讲清楚 Mockito 如何 Mock 依赖、如何覆盖分支条件
