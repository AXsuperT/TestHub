# TestHub - 企业级智能测试平台

## 项目简介

TestHub 是一套面向企业的一站式智能测试平台，覆盖**测试用例管理、接口自动化测试、UI 自动化测试、性能测试、缺陷管理、AI 智能助手**等核心能力，帮助测试团队实现测试全流程数字化、自动化与智能化。

## 技术栈

### 后端
- **框架**: Spring Boot 3.2 + MyBatis-Plus 3.5
- **数据库**: MySQL 8.0 + Redis
- **消息队列**: RabbitMQ（异步任务执行）
- **接口文档**: Knife4j (OpenAPI 3)
- **认证**: JWT
- **工具库**: Hutool、Fastjson2、Apache HttpClient5

### 前端
- **框架**: Vue 3 + TypeScript
- **UI 组件**: Element Plus
- **图表**: ECharts
- **状态管理**: Pinia
- **构建**: Vite

### 测试执行引擎 (Python)
- **接口测试**: requests + 自研断言引擎
- **UI 测试**: Selenium 4
- **性能测试**: Locust
- **报告**: Allure

### AI 能力
- 集成大模型 API，支持测试用例自动生成、缺陷根因分析、测试报告智能总结

## 核心功能

### 1. 测试用例管理
- 用例的增删改查、按模块/优先级/类型筛选
- 用例编号自动生成 (TC-00001)
- 支持功能、接口、UI、性能、安全等用例类型
- 用例状态流转：草稿 → 待评审 → 已评审 → 废弃

### 2. 接口自动化测试
- HTTP 请求构造（GET/POST/PUT/DELETE）
- 变量提取与传递（支持 `{{varName}}` 语法）
- 丰富断言引擎：状态码、JSONPath、包含、正则、数值比较等
- 测试套件批量执行
- 异步执行 + 执行记录持久化
- 详细的请求/响应/断言结果展示

### 3. UI 自动化测试
- 基于 Selenium 4 的步骤化执行
- 支持 open/click/input/select/assert/wait/screenshot 操作
- 多浏览器支持 (Chrome/Firefox)

### 4. 性能测试
- 基于 Locust 的并发压测
- 支持自定义并发数、启动速率、运行时长
- 响应时间统计：平均/最小/最大/P50/P90/P95/P99
- RPS、错误率计算

### 5. 缺陷管理
- 缺陷全生命周期管理：待处理 → 已分配 → 已修复 → 已验证 → 已关闭
- 严重程度分级：致命/严重/一般/轻微/建议
- 缺陷类型分类：功能/数据/UI/性能/安全

### 6. AI 智能助手
- **用例生成**: 根据需求描述自动生成覆盖正常/异常/边界场景的测试用例
- **缺陷分析**: 分析缺陷根因、影响范围、修复建议、回归测试建议
- **接口用例生成**: 根据 API 文档生成接口测试用例
- **报告总结**: 智能总结测试报告，给出质量评估和上线建议

## 快速开始

### 环境要求
- JDK 17+
- Maven 3.6+
- MySQL 8.0+
- Redis 6+
- RabbitMQ 3.10+
- Node.js 18+
- Python 3.9+

### 后端启动

```bash
# 1. 初始化数据库
mysql -u root -p < backend/src/main/resources/sql/testhub_init.sql

# 2. 修改 application.yml 中的数据库/Redis/RabbitMQ 配置

# 3. 启动后端
cd backend
mvn spring-boot:run
```

启动后访问 API 文档: http://localhost:8080/api/doc.html

### 前端启动

```bash
cd frontend
npm install
npm run dev
```

访问: http://localhost:5173 (默认账号 admin/admin123)

### Python 测试引擎

```bash
cd test-engine
pip install -r requirements.txt

# 运行接口测试
python run_test.py --type api --config api_test/example_cases.json --base-url http://localhost:8080/api

# 运行性能测试
python run_test.py --type perf --config perf_test/example_perf.json
```

## 数据库设计

核心表:
- `sys_user` / `sys_role` - 用户与权限
- `project` - 项目
- `test_case` / `test_case_module` - 测试用例与模块
- `api_case` / `api_test_suite` / `api_test_record` / `api_test_result` - 接口测试
- `ui_test_case` - UI 测试
- `bug` / `bug_comment` - 缺陷
- `ai_chat_record` - AI 对话记录

## 项目亮点

1. **完整测试闭环**: 从用例设计 → 自动化执行 → 缺陷管理 → 报告分析的全流程覆盖
2. **自研断言引擎**: 支持 10+ 种断言操作符，JSONPath 变量提取
3. **AI 赋能测试**: 大模型驱动的用例生成与缺陷分析
4. **双引擎架构**: Java 后端实时执行 + Python 引擎批量执行
5. **企业级架构**: RBAC 权限、异步任务、操作日志、全局异常处理
